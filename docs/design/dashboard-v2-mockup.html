naozhi dashboard 新原型 —— 精简版

对应 docs/rfc/planner.md v7 与 D75：一个主屏 + 一个状态页，没有顶层导航，也不再有专家视图模式。主屏三栏：左栏会话列表（等你 · Planner · 按工作区分组）、中间对话、右栏工作台（预览 · 产出 · 文件 · 详情；默认关闭，有可预览产物时自动打开并收起左栏；不放代码 diff）。三个面仍在：对话面 = 中栏，监督面 = 列表里的"等你"与 Planner + 状态页，工作台面 = 右栏。所有内容均为示意数据。
