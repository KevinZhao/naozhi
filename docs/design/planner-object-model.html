Planner 对象模型示意图

对应 docs/rfc/planner.md v7（§3–§7、§10，决策 D60–D74）。三张图：对象关系与基本行为、执行会话的生命周期、一个典型流程里各对象如何协作。mermaid 源码见 docs/design/planner-object-model.md。

① 对象关系与基本行为

三个角色（你 / Planner / 执行会话）、两种流动（消息 / 事件）、两份知识（懂你 / 懂系统），加上网关、一次性助手，以及收件箱和工作台面两个视图。v7 的变化：Planner 全局唯一，分层的是知识（懂你一份，懂系统按工作区分区）；工作区幕僚只是执行会话的一种用途；Planner 的介入按信任阶梯由你逐级放开；放行人只有你。

② 执行会话的生命周期

v7 未变：v7 未变：v7 未变：进程、上下文、记录分层回收，寿命跟产物走；蓝色虚线是"被唤醒"，前提是满足复活条件，否则另开新会话并附交接。

③ 典型流程：你交一个大任务后离开

v7：回执 → 派出 → 登记承诺 → 判权 → 按建议继续 → 工作区幕僚深度评审 → 意见（信任级别 1）→ 预判 → 提议 → 你拍板 → 一次性放行 → 复盘 → 第二天早报。紫色是对象自己的内部动作。
