Planner 对象模型示意图

对应 docs/rfc/planner.md v5 §3–§7。三张图：对象关系与基本行为、执行会话的生命周期、一个典型流程里各对象如何协作。mermaid 源码见 docs/design/planner-object-model.md。

① 对象关系与基本行为

三个角色（你 / Planner / 执行会话）、两种流动（消息 / 事件）、两份知识（懂你 / 懂系统），加上网关、一次性助手和收件箱视图。每个方框上半部是关键字段，"＋"开头的是基本行为；授权属于懂你，章程与例行任务属于 Planner。

② 执行会话的生命周期

进程、上下文、记录分层回收，寿命跟产物走；蓝色虚线是"被唤醒"，前提是满足复活条件，否则另开新会话并附交接。

③ 典型流程：你交一个大任务后离开

把各对象的基本行为串起来：路由 → 派出 → 判权 → 停顿判读 → 自动继续 → 过程评审 → 预判 → 推送 → 你拍板 → 复盘。紫色是对象自己的内部动作。
